QUICK ANSWERS

Good to know

Why do I need a mapping pack?

Legacy Gujarati fonts often assign different visible letters to different character codes. A pack supplies that font-specific table. This site includes the conversion engine, not proprietary mapping tables.

Will this install or provide the legacy font?

No. Font files are separate from text conversion. Use fonts you are licensed to install, and check that your target app has the right font available when viewing legacy output.

Why is my legacy font listed but conversion unavailable?

The catalog covers the font options named by the two reference sites. We have not verified a reusable license and tested a mapping for those fonts, so no legacy maps are bundled. Listing a name does not enable conversion. An imported pack is local user-provided data, not an independently verified map.

What can I do before importing a pack?

Select Unicode cleanup and press Convert now, or try the Unicode sample. NFC normalization standardizes canonically equivalent Unicode sequences; it does not decode legacy text, translate, transliterate, correct spelling, or change the typeface.
